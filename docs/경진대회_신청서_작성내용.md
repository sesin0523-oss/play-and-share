## 작품명
PLAY & SHARE (플레이 앤 셰어) - 취향을 나누는 YouTube 플레이리스트 공유 플랫폼

## 프로그래밍 언어
C# (.NET 8 · WPF · ASP.NET Core Web API), SQL (MySQL), HTML · JavaScript (YouTube IFrame API)

## 작품내용 (요약)
YouTube 음악으로 나만의 플레이리스트를 만들고, 다른 사람과 공유·추천받는 Windows 데스크톱 음악 큐레이션 플랫폼입니다.
① 공유와 발견: YouTube 검색으로 곡을 담아 플레이리스트를 만들고, 제목·곡·아티스트·태그로 검색하며 좋아요·댓글로 소통합니다. 사용자가 직접 분위기 태그를 만들 수 있습니다.
② 앱 안 재생: WebView2와 YouTube IFrame API로 곡을 누르면 앱 안에서 바로 재생되며, 하단 플레이어 바, 끌어서 옮기는 PiP 창, 전체화면, 이어 듣기를 지원합니다.
③ 데이터 기반 추천: 클릭·좋아요 기록으로 최근 7일/30일 순위, 오늘의 추천, 아직 열어보지 않은 플레이리스트와 처음 만나는 태그를 보여 주는 '취향 넓히기'를 제공합니다.
④ 기술 구성: WPF 클라이언트와 ASP.NET Core 서버를 REST API로 나누고 EF Core·MySQL로 데이터를 관리하며, 어두운/밝은 테마와 드래그 순서 변경 등 사용성을 갖췄습니다.
⑤ 시장성: 흩어진 YouTube 음악을 취향 단위로 모아 공유하는 커뮤니티형 서비스로, 동아리·카페·매장 BGM 공유 등으로 확장할 수 있습니다.
